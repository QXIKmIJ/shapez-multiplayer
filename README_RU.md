# Shapez Multiplayer Server

Небольшой независимый WebSocket relay/room-сервер для обычного мода `multiplay.js`. Автор проекта: **QXIK_mIJ**.

Сервер не содержит Shapez.io и не зависит от Steam или Electron. Игровой мир остаётся у хоста; сервер назначает игроков, проверяет совместимость, ограничивает трафик и пересылает подтверждённые хостом операции.

## Запуск

Откройте TCP-порт `7777` в Windows Firewall и на роутере, если друг подключается через интернет, затем запустите:

```powershell
.\shapez-multiplayer-server.exe --port 7777
```

По умолчанию сервер слушает `0.0.0.0:7777`, а комната вмещает 8 игроков вместе с хостом. Параметры:

```text
--port 7777
--host 0.0.0.0
--max-players 8
--config C:\path\config.json
```

При запуске `.exe` конфиг `config.json` читается рядом с исполняемым файлом. Параметры командной строки имеют приоритет. Секреты и учётные данные серверу не нужны.

## Сборка

Нужен установленный Node.js. Скрипт установит точные зависимости из `package-lock.json`, выполнит тесты и соберёт один `.exe`:

```powershell
.\build-server.ps1
```

Для сборки используется поддерживаемый форк `@yao-pkg/pkg`; runtime Node.js включается в `.exe`, поэтому другу Node.js не нужен.

## Протокол и защита

Протокол WebSocket v2 использует сообщения `hello`, `welcome`, `player-list`, `operation`, `operation-rejected`, `cursor`, `chat`, `hub-state`, `request-resync`, `resync`, `ping`, `pong`, `disconnect`. Установка/удаление, blueprint, рычаги, константные сигналы и апгрейды подтверждаются авторитетным хостом.

Сервер проверяет версию игры, версию multiplayer-мода и полный набор модов. Есть лимиты размера и частоты сообщений, отдельный лимит snapshot, защита от бинарного/некорректного JSON, WebSocket heartbeat и корректное закрытие комнаты при уходе хоста.
