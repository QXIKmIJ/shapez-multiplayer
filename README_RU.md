# Shapez Multiplayer Suite

[English Documentation](./README.md) | [Лицензия Apache 2.0](./LICENSE) | [Уведомление об авторстве](./NOTICE)

Полноценное серверное и клиентское решение для совместной игры в **Shapez.io** по сети в реальном времени.

**Архитектура:** Host-Authoritative (хост держит мир и валидирует операции, клиенты отправляют интенты).  
**Протокол:** Двунаправленный WebSocket v2 с батчингом, дедупликацией (sequence/id), кодами комнат `MPZ2:...` и горячей пересинхронизацией на лету (`applyFullDumpLive`).  
**Совместимость:** Steam-версия, standalone/portable сборки и веб-версия (без жестких зависимостей от Electron IPC).

## Быстрый старт на любом устройстве

### Шаг 1. Установка мода в игру
Запустите скрипт установки (он автоматически скопирует мод в каталог модов Shapez):
```powershell
.\install-mod.bat
```
*(Или вручную скопируйте файл `mod/multiplay.js` в `%APPDATA%\shapez.io\mods\`)*.

### Шаг 2. Запуск сервера
Запустите сервер (скрипт автоматически покажет ваши локальные и Tailscale IP):
```powershell
.\start-server.bat
```
*(Если скомпилирован бинарник, скрипт запустит `shapez-multiplayer-server.exe`. Если нет — запустит через `node server.js`)*.

По умолчанию сервер слушает порт `7777` (`0.0.0.0:7777`).

## Как играть

### 1. Игра на одном компьютере (локальный тест)
1. Запустите сервер: `.\start-server.bat`
2. Запустите игру Shapez. В главном меню нажмите кнопку **«Мультиплеер»**.
3. Выберите **«Открыть текущий мир (я — хост)»** и введите имя. Адрес оставьте по умолчанию: `ws://127.0.0.1:7777`.
4. Скопируйте сгенерированный инвайт-код (начинается с `MPZ2:...`).
5. Запустите второе окно игры, нажмите **«Мультиплеер»** -> **«Подключиться к другу»», вставьте код и нажмите подключиться.

### 2. Игра через Tailscale (Рекомендуется для игры через Интернет)
Самый быстрый и надежный способ играть через Интернет без необходимости открывать порты на роутере и без белого статического IP:
1. Установите и включите [Tailscale](https://tailscale.com/) на обоих устройствах.
2. Хост запускает `.\start-server.bat`. Скрипт автоматически определит и выведет ваш Tailscale IP:
   ```text
   Tailscale IP: ws://100.x.x.x:7777
   ```
3. При создании мира в игре хост указывает свой Tailscale-адрес: `ws://100.x.x.x:7777`.
4. Хост передаёт сгенерированный инвайт-код другу.
5. Друг вставляет инвайт-код и мгновенно подключается.

### 3. Игра по локальной сети (LAN / Домашний Wi-Fi)
1. Хост запускает `.\start-server.bat`. Скрипт отобразит локальный IP в сети (например, `192.168.0.x`).
2. В игре при создании комнаты хост указывает: `ws://192.168.0.x:7777`.
3. Друг подключается по выданному коду.

### 4. Игра через Интернет с прямым пробросом портов / на VPS
1. Откройте порт `7777` TCP на роутере/файрволе для хоста, либо разверните сервер на Linux/Windows VPS:
   ```bash
   node server.js --port 7777 --host 0.0.0.0
   ```
2. Хост и клиенты используют адрес сервера (например, `ws://vps.example.com:7777`).

## Возможности и механики мультиплеера

- **Синхронизация зданий и конвейеров:** постройка, поворот, удаление и замена конвейеров передаются мгновенно.
- **Поддержка чертежей (Blueprints):** вставка чертежей через Ctrl+C / Ctrl+V синхронизируется через оптимизированный `place-batch`.
- **Логика и провода:** интерактивные рычаги и диалоги настройки константных сигналов полностью реплицируются.
- **Синхронизация исследований и хаба:** апгрейды и уровень хаба синхронизируются в реальном времени.
- **Отображение курсоров игроков:** курсоры тиммейтов и их никнеймы рисуются поверх холста игры и масштабируются в зависимости от приближения камеры (`zoomLevel`).
- **Горячая синхронизация (Live Resync):** кнопка «Обновить мир» позволяет клиенту в 1 клик перезапросить полный слепок фабрики с хоста без выхода в меню. При этом сбрасываются конвейерные пути (устраняя «летающие предметы») и очищается кэш чанков карты с актуализацией seed.
- **Строгая проверка модов:** при подключении сверяются версии игры, мультиплеера и список установленных модов. При расхождениях подключение отклоняется с выводом подробного отчета.
- **Встроенный чат:** быстрый текстовый чат прямо в игровом HUD.

## Сборка сервера в автономный .exe

Для создания независимого исполняемого файла, не требующего установленного Node.js на целевой машине:

```powershell
.\build-server.ps1
```

Скрипт выполнит:
1. `npm install` (установка зависимостей из `package-lock.json`).
2. `npm test` (прогон полного набора unit/protocol/e2e тестов).
3. `npm run check` (статическая проверка синтаксиса).
4. Сборку через `@yao-pkg/pkg` в единый `shapez-multiplayer-server.exe` (Node 22 win-x64).
